# Numox.Vora Shell [v6.0]

A custom kernel-style interactive shell, parser engine, and LLVM virtual machine built using Flex, Bison, and Clang. Designed for custom architectures, secure scripting environments, and hardware emulation.

## Quick Install (From Source)

Make sure you have `flex`, `bison`, and `clang` installed (Works on Linux, macOS, and Termux/Android):

```bash
git clone https://github.com/bamiyor44/numox-vora.git
https://github.com/bamiyor44/numox-vora.git
cd numox-vora
make
